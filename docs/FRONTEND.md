# Frontend guide (for the frontend agent)

You own `frontend/`, `.github/workflows/pages.yml` and `frontend/eas.json`.
Read `AGENTS.md`, `docs/PROTOCOL.md` and `docs/RULES.md` first.

The frontend is **one React Native app written in TypeScript** that runs on **Android, iOS and the web**
from the same code, using **Expo**.

## Stack (fixed: don't swap it)

| Concern | Choice |
|---|---|
| Language | **TypeScript** (strict) |
| Framework | **React Native** through **Expo** (SDK 58; check `frontend/package.json`) |
| Platforms | Android, iOS, web (web via `react-native-web`) |
| Realtime | `socket.io-client` 4 |
| Storage | `@react-native-async-storage/async-storage` (works on all 3 platforms) |
| Fonts | `@expo-google-fonts/bangers`, `@expo-google-fonts/barlow-condensed` |
| Sound | `expo-audio` playing WAVs from `assets/sounds/` (generated by `scripts/make-sounds.mjs`), plus `expo-haptics` on phones |
| Clipboard / share | `expo-clipboard` on web, the React Native `Share` sheet on phones |
| Navigation | A screen enum in the store, with no router library. It's a 6-screen game, so keep it simple. |
| State | One small external store (`src/store.ts`) read with `useSyncExternalStore`. No Redux. |

Always add packages with `npx expo install <pkg>` (not `npm install`) so versions match the Expo SDK.
`frontend/AGENTS.md` holds Expo-specific tips. Expo changes between SDKs, so check the versioned docs at
`https://docs.expo.dev/versions/v58.0.0/` before using an Expo API you haven't used here yet.

## Visual reference

`docs/design/prototype.html` is the approved web design: pulp comic style, inked panels, hard offset shadows,
the Bangers display font, red ▲ / blue ● / neutral – / assassin ✖ marks for colour-blind safety, and light, dark and auto themes.
The React Native app reproduces it with `src/components/ui.tsx` (`Inked` draws the hard shadow the same way on every platform).

## Behaviour rules

* **Render only from `RoomView`.** Never compute the key on the client. Spymasters see colours only because `view.key` isn't null.
* **Phase routing** (in `App.tsx`): `lobby → play` goes to Board, `play → over` goes to Victory, `over → lobby` goes to Lobby.
* **UI permissions** (`perms()` in `Board.tsx`; the server re-checks every one):
  * The clue form shows if `me.role==='spymaster' && me.team===turn && !clue`.
  * Cards can be tapped if `me.role==='agent' && me.team===turn && clue`.
  * End turn shows for agents of the current team once `guessesThisTurn ≥ 1`.
  * Settings, Start and Rematch are enabled for `isHost` only. The lobby says why Start is disabled (`notReady()`).
* **Timer:** `turnEndsAt - (Date.now() + skew)`, where `skew = serverNow - Date.now()`. There's a tick sound in the last 10 s. The client never ends a turn on its own.
* **Errors:** show `ack.error.message` in the screen's `Note`.
* **Connection banner:** "Waking the server…" (Render free can take up to 60 s) and "Reconnecting…".
* **Session:** `cnSession {code, playerId, token}` lives in AsyncStorage. The app rejoins on every socket `connect`. It's cleared on leave and on `room:closed`.
* **Invites:** on web, `?room=CODE` pre-fills Home and the lobby copies an invite link. On phones the lobby opens the share sheet with the code.
* **Animations** (React Native `Animated`, no extra library):
  * Card reveal: the card flips (scaleX), bounces, and a comic word pops out of it: BAM! (own colour), OOPS! (other team), MEH (neutral), BOOM! (assassin, plus a shake).
  * New clue: a speech bubble "▲ Red spymaster says OCEAN · 2" springs over the board for about 2 s, for every player.
  * Both are driven by `room:state` changes, so everyone sees them. Nothing animates for state that already existed when you joined, and animations are skipped when the OS has reduced motion turned on.
* **Accessibility:** every pressable has a role and label, cards announce their colour when it's known, and status texts use `accessibilityLiveRegion`.
* **Layout:** works at 360 px wide. The board is always 5×5, and content is capped at 720 px wide on tablets and desktop.

## Commands

```bash
cd frontend
npm install                 # first time
npx expo start              # dev server: press w (web), a (Android emulator), i (iOS simulator, macOS only)
                            # or scan the QR code with the free Expo Go app on a real phone
npm run typecheck           # must pass before every commit
npm run build:web           # static web build into dist/ (what GitHub Pages serves)
npm run sounds              # regenerate assets/sounds/*.wav
```

On a real phone the app must reach the backend on your computer's LAN IP:
`EXPO_PUBLIC_SERVER_URL=http://192.168.1.20:3000 npx expo start`.

**Testing without a backend:** on web, open the console and call `cn.setView(fakeRoomView)` to render any state.

## Definition of done (frontend)

* `npm run typecheck` passes and `npm run build:web` succeeds.
* Two windows or devices can play a full game against the local backend (one spymaster and one agent per team).
* Checked on web, plus at least one of Android emulator / iOS simulator / Expo Go.
* No red errors in the console. Light and dark themes are both readable.
* `docs/STATUS.md` updated, committed **and pushed**.
